## Confirmed defects fixed at this audit

- `GameSession._apply_active_quest_event_ids()` used to append quest nodes and fan edges from all layer-two nodes. Concurrent eligible quests could exceed the Master Spec's three-outgoing-edge limit. It now reuses existing layer-three nodes; `SectorGenerator.validate_graph()` runs after all graph modifiers. Regression: two active B03 quest stages through GameSession save/reload.
- E10's catalogued, interruptible summon was filtered out and had no resolver. The shared simulator now executes it through the existing summon cap/no-loot path. Regression checks telegraph, E20 owner and snapshot roundtrip.
- Tree node R3D (`ON_ATTACK_COUNTER`) was rejected by the simulation guard and its description-specific same-target counter was absent. It now counts operator attacks per target, resets on target switch, applies the authored buff and survives combat snapshot roundtrip.
